# 0008 演员属于聊天，全局只保留演员库

日期：2026-09-24 · 状态：已采用（推翻 ADR-0001 中"演员存在全局设置里"的存放位置，其余不变）

## 背景

最初演员存在 `extension_settings` 里，所有角色卡、所有聊天共用同一批演员；用户反馈不同角色卡的演员混在一起。

## 决定

- 演员列表随聊天保存：`chat_metadata['persona-arena'].actors`。演员、面板、回合、沙龙、私语、罗盘、史官日志全部按"某张角色卡的某个聊天"隔离。
- `extension_settings['persona-arena'].actors` 改为**演员库**：模板。新建演员时可勾选"同时存入演员库"；详情页可"存入演员库"；任何聊天可从库里"邀请"（复制一份，保留 `libraryId`）。
- 迁移：打开一个尚无 `actors` 字段的聊天时，若它的 `actorState` 里有某些演员的面板记录，就从演员库复制这些演员进来；其它聊天从空开始。
- 连接、原著梗概、偏好仍是全局的。

## 理由

- 演员的面板、羁绊、经历本来就随聊天保存，把演员本体也放进去才一致；同一个 ID 在不同聊天里互不影响。
- 演员库保留了跨聊天复用的便利，且复制而非引用，避免一处改动影响所有戏。

## 代价

- 聊天元数据变大（每位演员约 2–4 KB）。
- 没有打开聊天时无法添加演员（界面会提示）。
