# 0005 剧情引导通过 setExtensionPrompt 注入正文，而不是改写玩家消息

日期：2026-09-24 · 状态：已采用

## 背景

罗盘的"引导"需要影响舞台上的主 AI。可选：把引导拼进玩家要发送的汇总文本；或用酒馆的扩展提示注入。

## 决定

用 `SillyTavern.getContext().setExtensionPrompt('PERSONA_ARENA_PLOT', text, IN_CHAT=1, depth, scan=false, role)`。切换聊天（`CHAT_CHANGED`）与插件启动时按当前聊天的状态重设或清空；玩家可在剧情页关闭注入、改深度与角色、改写引导原文。

## 理由

- 引导是幕后指令，不应出现在聊天记录里，也不应污染玩家的发言。
- 扩展提示随每次生成自动带上，包括玩家手打的消息、重生成与继续，而汇总文本只在演员回合时才发送。
- 深度可调：depth 1 在最后一条消息之前，足够靠近生成点；role 可切 system/user/assistant 适配不同模型。

## 代价

- 扩展提示是全局内存态，插件必须在切聊天时维护，否则会把 A 聊天的引导带进 B 聊天（已处理）。
- 不进入聊天文件，分支/回滚不会带走它，但罗盘本身存在聊天元数据里，切回即重设。
