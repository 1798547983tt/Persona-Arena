# 0007 破限条目作为第一条 system 消息，并附桥接说明

日期：2026-09-24 · 状态：已采用

## 背景

用户提供了自己的酒馆预设（2609010.json），要求把其中的破限提示词作为"后台的最高系统提示词"缝进插件，可开关，且不影响功能。

## 决定

- 从预设的 `prompt_order` 中取「━━ 破限 ━━」区段内的条目，原文不改，随插件内置（`src/data/jailbreak-2609010.js`）；玩家也可导入自己的预设 JSON 重新提取。
- 开启时，`connections.sendChat` 把拼接后的文本作为**第一条** system 消息插到每次调用的最前面（连接测试除外）；条目里的 `{{setvar::…}}` 宏被剥离以避免副作用，其余宏交给酒馆替换。
- 文本末尾固定附一句桥接说明：预设里的"讲述者/绘梨衣"指此刻执笔的 AI 本身，输出格式一律以后面的任务指令为准。

## 理由

- 放在最前面才是"最高系统提示"；Claude 等把开头连续的 system 合并为 system 参数，位置正确。
- 桥接说明解决了预设人格名与插件演员身份的冲突，以及格式指令的优先级，使 `<move>`/`<state>` 等契约不受影响。

## 代价

- 每次调用多出约 1.5k 字的提示；对按 token 计费的连接有成本。
- 默认关闭，需要玩家自己在设置里开启。
